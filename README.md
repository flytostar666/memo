# star备忘录

一个 Windows 专用的本地备忘录，以星空为视觉主题。无需联网即可使用。

主要功能：

- 普通备忘录支持标题、正文、搜索、置顶、编辑和回收站。
- 加密星匣包含“密码记录”和“加密备忘”两种模式。
- 加密数据使用 PBKDF2-SHA256（120 万次）派生密钥，并通过 AES-256-GCM 加密保存。
- 每次进入加密栏都需要输入 6 位访问密码，离开分类或 2 分钟无操作后自动锁定。
- 支持在验证原密码后重置加密密码，所有加密记录会重新加密。
- 支持 JSON 备份导入和导出。

## 安装

从 GitHub Releases 下载：

- `Star-Memo-Setup-1.1.1.exe`：安装版，可选择安装位置。
- `Star-Memo-Portable-1.1.1.exe`：免安装版，直接双击运行。

当前版本不包含自动更新。

发布新版本时，在提交代码后推送版本标签即可自动构建并创建 GitHub
Release：

```powershell
git tag v1.1.1
git push origin v1.1.1
```

## 本地开发

```powershell
npm install
npm start
```

构建 Windows 安装版和免安装版：

```powershell
npm run dist:win
```

构建产物位于 `release/`。

## 网页版本

开发时可以双击 `打开star备忘录预览.cmd`，或运行 `node serve.js` 后访问
`http://127.0.0.1:8765/preview-star.html`。

## 数据与隐私

普通记录保存在当前 Windows 用户的本地应用数据目录中，不会上传至网络。加密星匣中的标题、正文、账号和密码均以密文保存。

6 位数字访问密码的抗暴力破解能力有限，请妥善保护密码，并避免用它保护风险极高的账号。忘记访问密码后，加密星匣中的数据无法恢复。软件不提供自动更新。
